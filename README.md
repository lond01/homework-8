# Завдання 3 — Вибір мови програмування

## Опис
Програма створює вікно з трьома радіо-кнопками для вибору мови програмування: Python, Java та C++. Після натискання кнопки «Підтвердити» з'являється повідомлення з вибраною мовою.

## Використані технології
- Python
- Tkinter — створення графічного інтерфейсу
- Messagebox — виведення повідомлень
- Radiobutton — вибір мови програмування

## Як працює програма
1. Відкривається вікно програми.
2. Користувач обирає одну з трьох мов.
3. Натискає кнопку «Підтвердити».
4. Програма показує повідомлення з вибраною мовою.
